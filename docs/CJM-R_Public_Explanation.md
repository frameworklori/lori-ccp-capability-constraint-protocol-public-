# CJM-R Public Explanation

CJM-R is the rule-based Capability Jump Monitor.

It estimates whether a response gives a non-expert user practical progress toward harmful capability. The public description intentionally avoids full scoring logic and thresholds.

## Public Signals

- Last-Mile Reduction: whether the response closes a practical gap.
- Synthesis Density: whether the response combines several enabling ideas.
- Trajectory Fit: whether the response aligns with a risky user trajectory.
- Agentic Pattern Score: whether the response enables planning, automation, or iteration.

## Public Interpretation

CJM-R is meant to flag capability transfer, not merely sensitive vocabulary. It is conservative when a response appears to transform vague intent into practical enablement.
