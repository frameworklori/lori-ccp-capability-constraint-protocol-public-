# Limitations

CCP is not a complete safety system.

Known limitations include:

- Ambiguous intent can cause false positives or false negatives.
- Multi-turn accumulation can hide risk.
- Domain expertise may be needed to judge capability transfer.
- Redacted public examples cannot fully represent adversarial behavior.
- Learned evaluators may inherit blind spots.

The public repository omits sensitive details by design. Production systems require private, access-controlled evaluation data and expert review.
